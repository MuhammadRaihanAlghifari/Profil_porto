Engineering Discipline

Applied Problem-Solving Framework

Every system I have developed follows a three-stage methodology to ensure real-world viability and technical stability.

STAGE 01 User Context

Engage

Understand operational reality on the ground. Interview stakeholders, observe frontline workflows in hospital wards, evaluation boards, or sales teams, and identify true bottlenecks rather than theoretical symptoms.

Focus: Requirement elicitation, user journey mapping, pain-point definition.
STAGE 02 Architecture

Investigate

Map out data dependencies, analyze existing database schemas (e.g. 1,000+ tables in SIMRS), design conversation decision trees, and establish clear boundary rules between automated AI tasks and human authorities.

Focus: Relational data modeling, API contract design, boundary guardrails.
STAGE 03 Implementation

Act

Construct clean, maintainable code using Node.js, Express, PostgreSQL, MySQL, and Tailwind CSS. Implement end-to-end testing, deploy intuitive UI screens, and validate with actual users and live transaction records.

Focus: Full-stack implementation, testing & debugging, user validation.
